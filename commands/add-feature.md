Add this feature to the current application: $ARGUMENTS

1. Read `docs/plan.md`, `docs/design.md` and `docs/adr/` to learn the app's conventions.
2. Use the `design-doc-analyzer` skill to append a new feature section to `docs/plan.md`:
   entities, endpoints, screens and tasks. Show it and wait for approval.
3. Implement it as one vertical slice (migration → backend → tests → frontend → tests),
   following the same skills as the original build. Add a new Flyway migration; never
   edit a migration that has already been applied.
4. Run all backend and frontend tests, then rebuild with the `docker-local` skill.
5. Commit with a `feat(<feature>): ...` message and report what changed.
